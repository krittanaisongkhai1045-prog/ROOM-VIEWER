# Room Viewer — ตารางขอเข้าห้อง (ดูอย่างเดียว)

เว็บแยกสำหรับให้คนอื่นเปิดดูการขอเข้าห้องได้อย่างเดียว ไม่ต้องล็อกอิน
- ดูสถานะห้องแบบเรียลไทม์ (อัปเดตทุก 30 วินาที), เลือกวันย้อนหลัง/ล่วงหน้า, ดูภาพสรุปรายวัน
- แตะห้อง/คำขอ เพื่อดูรายละเอียดและรูปเอกสาร/Before/After
- โหลดรูปทั้งหมดของคำขอ (ZIP) และส่งออกตารางเป็น PDF/PNG (เลือกอาคาร/ชั้น แยกไฟล์ได้ แนบรายละเอียดห้องได้)
- แก้ไข/เพิ่ม/ลบไม่ได้ (บังคับดูอย่างเดียวทั้งในหน้าเว็บ — และฝั่งเซิร์ฟเวอร์ใช้ RLS ของ Supabase เดิม)

## ติดตั้ง
1. สร้าง repo ใหม่บน GitHub (เช่น `room-viewer`) อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ → Settings → Pages
2. ใช้ `config.js` ชุดเดียวกับ Inspection Desk (ฐานข้อมูล Supabase เดียวกัน) ข้อมูลจึงตรงกันอัตโนมัติ
3. เว็บนี้อ่านได้เฉพาะเอกสารที่ตั้งสิทธิ์เป็น **"ทุกคนอ่านได้"** (ค่าเริ่มต้นของเอกสารใหม่) — ถ้าคำขอใดตั้งเป็นเฉพาะสมาชิก จะไม่แสดงในเว็บนี้
4. โหลดเฉพาะข้อมูลขอเข้าห้องและชื่อโครงการ ไม่ดึงใบตรวจ/DEFECT/QC
